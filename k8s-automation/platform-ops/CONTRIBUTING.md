## Overview

This repo contains operational knowledge — runbooks, SOPs, and postmortems for the PlatRel platform team.

## Before you contribute

1. Use `_template.md` files as the starting point for new runbooks and postmortems
2. Every incident must produce or update a runbook within 48 hours
3. Postmortems are blameless — focus on system conditions, not individuals

## Pull request process

- Runbooks must be tested before marking `last_tested` date
- Link runbook PRs to the incident ticket
- Update related skills in platform-skills if agent context was missing
